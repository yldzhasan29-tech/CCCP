# Попутка ИИ — MVP

Это демонстрационный веб-MVP кейса 10 «Студенческий райдшеринг “Попутка ИИ”».

## Запуск
Самый простой вариант:
1. Распакуйте архив.
2. Откройте `index.html` в браузере.

Для разработки можно использовать VS Code + расширение Live Server.

## Что уже работает
- адаптивный сайт для телефона и ПК;
- поиск поездки по времени;
- AI-like matching с процентом совпадения;
- карточки водителей, машин, рейтинга, мест и цены;
- страница подробностей;
- бронирование в демо-режиме;
- демонстрационный вход студента.

## Важно
Это frontend-only MVP: база данных, настоящий LLM, авторизация через @urfu.ru, карты и платежи пока заменены демонстрационной логикой. Для хакатона это позволяет сначала показать полный пользовательский сценарий, а затем подключить backend/LLM.
