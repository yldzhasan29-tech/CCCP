# Попутка ИИ — студенческий райдшеринг (Кейс 10, без заказчика)

Рабочий прототип для хакатона: мобильное веб-приложение, в котором
студенты УрФУ с автомобилями публикуют свои маршруты до Новокольцовского
кампуса, а пассажиры находят попутчиков по пути. Решает проблему из
брифа: дорогое такси (400–700 ₽) и переполненные редкие автобусы.

## Стек
- **Backend:** Python 3 + Flask, SQLite (без внешних сервисов — всё работает офлайн)
- **Frontend:** обычные HTML/CSS/JavaScript (без сборки, без фреймворков)

## Как запустить

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Перейти в backend и создать базу с демо-данными
cd backend
python seed_data.py

# 3. Запустить сервер
python app.py
```

Открыть **http://127.0.0.1:5000** — фронтенд отдаётся тем же Flask-сервером.

Демо-аккаунты (все верифицированы через `@stud.urfu.ru`) выводятся в
консоль после `seed_data.py`, например `artem.sokolov@stud.urfu.ru` —
уже опубликовал маршрут «Уралмаш → кампус, 08:30».

## Как устроены 4 AI-фичи из брифа

| Фича из брифа | Где реализована | Как это работает |
|---|---|---|
| **Умный матчинг** | `backend/matching.py` | Жёсткие фильтры (направление, зона, свободные места, окно ±15 мин) + скоринг по близости времени, совпадению предпочтений (музыка/разговорчивость), заполненности машины и рейтингу водителя. Возвращает ранжированный список кандидатов. |
| **Прогнозирование спроса** | `backend/demand.py` | Считает историческую статистику заявок по часам и направлениям, сравнивает со предложением мест, находит "разрыв" спрос-предложение и предлагает % бонуса водителям в непопулярные, но нужные часы. Прозрачная статистическая модель — легко объяснить жюри и в будущем заменить на ML/LLM без изменения API. |
| **Динамическое ценообразование** | `backend/pricing.py` | Цена = расстояние (км) × базовый тариф × коэффициент трафика (час пик/не пик, аналог данных из API Яндекс.Карт) ÷ число пассажиров в машине. Всегда дешевле такси и не ниже "топливного пола" для водителя. |
| **Безопасность** | `backend/app.py` (`_require_verified`) + таблица `users`/`ratings` | Регистрация только с университетской почтой `@stud.urfu.ru`; публиковать маршрут/искать попутку может только верифицированный пользователь; после поездки — взаимные оценки 1–5, средний рейтинг влияет на скоринг матчинга; хранится экстренный контакт. |

## Структура проекта

```
poputka-ai/
├── backend/
│   ├── app.py          # Flask API — все эндпоинты
│   ├── database.py     # SQLite-схема + справочник зон/расстояний
│   ├── matching.py      # умный матчинг
│   ├── pricing.py       # динамическое ценообразование
│   ├── demand.py        # прогнозирование спроса
│   └── seed_data.py     # демо-данные для презентации
├── frontend/
│   ├── index.html
│   ├── style.css
│   └── app.js
└── requirements.txt
```

## Идеи для доработки после хакатона
- Заменить справочник зон/расстояний на реальный вызов Яндекс.Карт API.
- Заменить статистическую модель прогноза спроса на LLM/ML-предсказание с учётом погоды, расписания пар и праздников.
- Push-уведомления о найденном совпадении, чат между водителем и пассажиром.
- Мобильное приложение (React Native / Flutter) поверх того же Flask API.
