# Как участвовать · Nasıl katkı verilir

Команда не пишет код руками — правки формулируются словами, а вносятся через ИИ.
Поэтому самое ценное, что вы можете дать, — **точное описание того, что не так**.

*Takım kodu elle yazmıyor — düzeltmeler kelimelerle tarif ediliyor, uygulaması yapay zekâ ile
yapılıyor. Bu yüzden en değerli katkı, **neyin yanlış olduğunun net tarifi**.*

---

## 1. Запустить у себя (30 секунд)

Сборка не нужна: ни `npm install`, ни бандлера.

```bash
git clone <URL репозитория>
cd poputka-ai
python3 -m http.server 8000
# открыть http://localhost:8000
```

Либо просто открыть `index.html` двойным щелчком.

## 2. Как сообщить о проблеме

Открыть **Issues → New issue** и выбрать шаблон:

| Шаблон | Когда |
|---|---|
| 🐞 Ошибка | что-то не работает, ломается, выдаёт не то |
| 🎨 Правка интерфейса | экран неудобный, непонятный или некрасивый |
| 🌍 Перевод | текст на каком-то из 8 языков звучит криво |

Обязательно приложить: **какой экран**, **какой язык интерфейса**, **что сделали**,
**что ожидали**, **что получилось**. Скриншот стоит десяти абзацев.

## 3. Ветки и коммиты

```
main            — то, что показываем жюри. Всегда рабочее.
feat/<коротко>  — новая функциональность
fix/<коротко>   — исправление
```

Коммит одной строкой, по-русски или по-английски: `fix: карта не перерисовывается при смене языка`.

Перед пушем в `main` убедиться, что открывается главная, поиск и чат — этого достаточно.

## 4. Что проверяет CI

На каждый push и pull request автоматически запускается:

* синтаксическая проверка всех файлов в `src/`
* сверка ключей во всех 8 файлах локализации (`scripts/check-locales.js`)

Если проверка красная — мержить нельзя.

## 5. Где что лежит

| Хочу поправить | Файл |
|---|---|
| Текст на любом языке | `src/locales/<код>.js` |
| Цвета, шрифты, отступы, тени | `styles/tokens.css` |
| Вид кнопок, карточек, чата | `styles/components.css` |
| Раскладку страниц, адаптив, RTL | `styles/views.css` |
| Логику подбора попутчиков | `src/matching.js` |
| Промпты и офлайн-разбор объявлений | `src/ai.js` |
| Остановки и координаты | `src/places.js` |
| Демо-данные для показа | `src/seed.js` |
| Конкретный экран | `src/views/<экран>.js` |

**Важно:** добавили ключ в `src/locales/ru.js` — добавьте его во все остальные 7 файлов,
иначе CI не пропустит.
