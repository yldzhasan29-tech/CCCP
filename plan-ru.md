# Попутка ИИ — план проекта для хакатона (обновлено)

**Дедлайн: 8 сентября (в этот же день — презентация)**
**Начало работы: сегодня, 4 сентября**

---

## 1. Что делаем

Кейс 10 из PDF хакатона: студенческий райдшеринг между центром и Новокольцовским кампусом УрФУ. Студенты-водители публикуют регулярные маршруты, студенты-пассажиры находят попутчиков по маршруту/времени/рейтингу. Цена ниже такси, но с компенсацией бензина водителю.

**Цель:** рабочий MVP, который за пару минут показывает жюри реальный сценарий поездки от начала до конца, с использованием AI.

---

## 2. Формат: веб-приложение (React), а не бот

Изначально планировали Telegram-бота, но организаторы сказали, что бот — слишком простое решение. Поэтому переходим на **отдельное веб-приложение**.

Логика и вся серверная часть, которую мы уже спроектировали, остаются практически без изменений — меняется только интерфейс:

| Остаётся как было | Меняется |
|---|---|
| Синтетические данные (30–50 водителей/пассажиров) | Сообщение в чате → форма/экран |
| Формула скоринга (маршрут/время/рейтинг/предпочтения) | Inline-кнопка → обычная HTML-кнопка |
| Интеграция LLM (Groq/Gemini, бесплатно) | Библиотека бота (aiogram) → React |
| Объяснение «почему совпадение» по шаблону | — |
| Без реального бэкенда/БД, без реальной аутентификации | Вместо верификации через e-mail — простой экран «введите имя» |
| Формула цены (расстояние × коэффициент) | — |

---

## 3. Стек

- **React (через Vite)** — быстро разворачивается, подходит новичкам
- **Vercel/Netlify** — бесплатный деплой в один клик (ссылка работает без ноутбука в руках, что снижает риск на демо)
- **Groq API или Google Gemini API** — бесплатный тариф
- Реального бэкенда/БД нет — данные хранятся в состоянии React / localStorage

---

- Бюджет: ноль, только бесплатные тарифы

## 5. Что делаем (обязательно) и что НЕ делаем

### Обязательно:
- Три экрана: главный экран (выбор роли + форма), список результатов, подтверждение бронирования
- Синтетические данные (30–50 «фейковых» пользователей)
- Скоринг: маршрут 40%, время 30%, рейтинг 15%, предпочтения 15%
- Один вызов LLM: разбор свободного текста в структурированный JSON
- Объяснение «почему совпадение» — по шаблону, без LLM
- Простая формула цены, без реального трафика
- Карточки результатов с понятным дизайном + кнопка «Забронировать»

### НЕ делаем:
- Реальную регистрацию/верификацию по e-mail → просто поле «введите имя/юзернейм»
- Реальную интеграцию с картами → максимум статичный Leaflet (бесплатно, без ключа) или текстовое описание маршрута
- Прогноз спроса и «Smart Crew» → только в презентации как «планы на будущее»
- Отдельный бэкенд-сервер и настоящую базу данных

## 7. Структура защиты

1. Проблема — студенты теряют время и деньги на дорогу до кампуса
2. Решение — приложение соединяет студентов по маршруту
3. AI — LLM понимает запрос на естественном языке и объясняет совпадения
4. Демо — главная часть
5. Impact — дешевле, меньше пустых мест в машинах
6. Будущее — прогноз спроса, Smart Crew, интеграция с университетом (только словами)
